# The Python environment for tools/release_gate.py's subprocesses: the

# `tokenizers`). The gate itself uses only the standard library.

# pillow, torchvision, torchaudio and torchcodec are here only because mteb
# refuses to load google/embeddinggemma-2's wrapper (a multimodal model)
# without its image, audio and video extras; the gate embeds text only.
#
# Every package is pinned to the version the committed baseline
# (docs/data/release-gate.json) was measured with, so a rebuilt
# environment reproduces it. Python 3.12:
#
#   uv venv --python 3.12 <dir>
#   uv pip install --python <dir>/bin/python -r tools/release_gate.requirements.txt
#
# (or `python3.12 -m venv <dir>` and `<dir>/bin/pip install -r ...`). Then
# point the gate at it with `--python <dir>/bin/python`, or set
# SIDEKICK_GATE_PYTHON to that interpreter.
