First release: an OpenAI-compatible daemon over Apple on-device inference, hardware-verified on Apple Silicon.

- Foundation Models chat, including constrained decoding.
- ANE-resident Core ML embeddings: bge-small and EmbeddingGemma-300m, via the conversion recipes in `tools/`.
- A static floor tier that runs anywhere.
- `libsidekick.dylib` for in-process embedding hosts.
